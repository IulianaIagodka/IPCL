# IPCL agent process

## Перед новою роботою
1. Створити TodoWrite таски на всю роботу.
2. Відкрити `OWNERS.md` — чи тема вже має owner / PR.
3. Викликати `cursor-cloud/list-cloud-agents` (RUNNING/IDLE/WAITING) і перевірити:
   - ті самі ADR / теми / файли / PR;
   - overlapping гілки (`cursor/implement-adr-*`, MVP, UI);
   - дублікати назв агентів.
4. Якщо є конфлікт — не дублювати: задача лише в `BACKLOG.md`.
5. Нова задача → пріоритизація (P0–P3) → `BACKLOG.md` (+ owner у `OWNERS.md` якщо новий) → виконання.

## Щодня о 08:00 Europe/Kyiv
Таймер `daily-plan-0800-kyiv` (cron `0 5 * * *` UTC = 08:00 EEST / узимку змінити на `0 6 * * *` для EET).
На пробудженні:
1. Оновити список агентів і гілок (`git fetch` + tips).
2. Оновити `BACKLOG.md` (конфлікти, P0–P3, Done).
3. Надіслати план користувачу українською.
4. Не стартувати нову імплементацію без пріоритизації в беклог.
5. Перевірити `expiresAt` таймера; якщо < 48 год — re-subscribe.

## Пріоритети
- **P0** — блокери / конфлікти агентів / зламаний main
- **P1** — активна імплементація ADR, що вже в роботі
- **P2** — наступний ADR / інтеграція після merge
- **P3** — polish, docs, brand, nice-to-have
